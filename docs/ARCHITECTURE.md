# CareerPilot AI / ACIF Architecture

Core flow:

Student Action
→ Raw Data
→ Evidence
→ Skill Evidence Graph
→ Temporal Career Twin
→ ACIF
→ Career Match / Confidence / Opportunity Gaps / Readiness
→ Explainability
→ Career GPS / Simulator / Copilot
→ New Student Action
→ Twin Update

The product and research layers are intentionally separated:
- CareerPilot AI = deployable product.
- ACIF = evidence-aware, temporally adaptive career-intelligence framework.
